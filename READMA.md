# Football Player Performance Analytics Dashboard

An interactive football analytics dashboard developed using Python, Streamlit, Pandas, and Plotly.

> **Synthetic Data Notice:** The dataset contains sample football player statistics for educational and demonstration purposes. It does not represent verified real-world match statistics.

---

## Features

- **Overview** – Display total players, goals, assists, and appearances.
- **Player Analysis** – Explore individual player performance.
- **Team Analysis** – Compare team goals and performance.
- **Position Analysis** – Analyze players by their positions.
- **Data Explorer** – Search and explore football player statistics.
- **Interactive Charts** – Visualize football data using Plotly.
- **Team Filter** – Filter player statistics by team.
- **User-Friendly Interface** – Simple and interactive dashboard design.

## Installation

### Prerequisites

- Python 3.9 or later
- Visual Studio Code

### Steps

1. Download or clone the project repository.

2. Open the project folder in VS Code.

3. Install the required libraries:

   pip install -r requirements.txt

---

## Running Locally

Run the following command in the VS Code terminal:

    streamlit run app.py

The dashboard will open in your web browser.

---

## Deploying to Streamlit Community Cloud

1. Upload the project files to a public GitHub repository.
2. Sign in to Streamlit Community Cloud using GitHub.
3. Create a new application.
4. Select your GitHub repository.
5. Set the main file path to app.py.
6. Click Deploy.
